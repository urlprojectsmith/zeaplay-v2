# Phase 15.3 Feature Enforcement Matrix

This artifact certifies the Phase 15.3 backend commercial-feature enforcement surface. The executable source of truth is apps/api/src/modules/billing/phase15-3-feature-enforcement.matrix.ts; phase15-3-feature-enforcement-matrix.spec.ts reflects over the controlled Nest controllers and fails when a non-GET mutation route is missing from this matrix.

- Reads remain allowed when a feature is disabled so existing data stays recoverable.
- Reduction and recovery operations remain allowed where they reduce usage, disable activity, archive data, delete data, or preserve historical consistency.
- Generic REST is not commercially gated because the current Phase 15.3 feature catalog has no Generic REST feature key; SSRF, credential, fixed-origin, and action safeguards remain authoritative.
- Worker/internal entries are listed separately when the entry point is not a controller route.
