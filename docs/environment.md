# Environment

Environment variables are validated at startup by `@zea-play/config`.

Groups:

- App URLs and ports: `WEB_PORT`, `API_PORT`, `WORKER_PORT`, `WEB_APP_URL`, `API_PUBLIC_URL`
- HTTP limits: `REQUEST_BODY_LIMIT`
- Database: `DATABASE_URL`, `DIRECT_DATABASE_URL`
- Redis: `REDIS_CACHE_URL`, `REDIS_QUEUE_URL`, `REDIS_REALTIME_URL`, `REDIS_RATE_LIMIT_URL`
- Auth: `JWT_ACCESS_SECRET`, `ACCESS_TOKEN_TTL_SECONDS`, `REFRESH_TOKEN_TTL_SECONDS`, `REFRESH_TOKEN_COOKIE_NAME`, `CSRF_COOKIE_NAME`, `AUTH_COOKIE_DOMAIN`, `LOGIN_RATE_LIMIT_WINDOW_SECONDS`, `LOGIN_RATE_LIMIT_MAX_ATTEMPTS`
- Uploads: `MAX_UPLOAD_BYTES`, `ALLOWED_MIME_TYPES`, `UPLOAD_URL_TTL_SECONDS`, `DOWNLOAD_URL_TTL_SECONDS`, `DEFAULT_STORAGE_LIMIT_BYTES`
- Object storage: `MINIO_ENDPOINT`, `MINIO_PORT`, `MINIO_ACCESS_KEY`, `MINIO_SECRET_KEY`, `MINIO_BUCKET`
- Object storage transport: `MINIO_USE_SSL`
- SMTP placeholders: `SMTP_HOST`, `SMTP_PORT`
- Observability: `SENTRY_DSN`, `NEXT_PUBLIC_SENTRY_DSN`, `OTEL_SERVICE_NAME`, `OTEL_EXPORTER_OTLP_ENDPOINT`

Never commit real secrets.
