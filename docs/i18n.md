# I18N

Phase 5 includes an English/Tamil localization foundation. Translations are grouped by `common`, `navigation`, and `dashboard` namespaces in `apps/web/lib/i18n.ts`.

`LanguageProvider` persists the selected locale in `localStorage` under `zea-play-locale` until backend preference support exists. English is the fallback language. Tamil text is rendered directly and covered by focused tests.

Only Phase 5 shell UI is translated. Future business modules should add their own namespace entries when implemented.
